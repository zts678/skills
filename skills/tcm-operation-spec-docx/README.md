# tcm-operation-spec-docx 技能说明（中文）

按统一体例与排版生成**《中医XX操作技术规范.docx》**系列文档的工作区技能。

核心做法：**检索权威标准原文 → 按固定体例撰写 → 脚本生成 docx → 排版门禁校验 → 交付并清理临时文件**。

> 最高约束：一切技术内容必须来自权威资料原文，禁止凭印象编造参数、分级、剂量、禁忌。查不到权威依据的内容宁可不写。

---

## 一、什么时候触发

在本工作区内，用户提出下列请求时使用本技能：

- "生成/做一份《中医XX操作技术规范.docx》"
- "再创建一份中医XX治疗操作技术规范"
- 修复已生成规范的排版问题（如"封面不一致"）

不适用于：通用 Word 排版任务、无权威来源支撑的科普文章、工作区以外目录。

```

│   ├── build_spec_docx.py           # docx 生成器（排版函数锁定，只填内容）
```

## 三、五阶段工作流（详见 SKILL.md）

| 阶段 | 要点 |
|---|---|
| 1 调研 | 先辨析近名技术（如松动术≠松解术）；按团体标准→国/行标→规划教材→共识→期刊的优先级检索；下载 PDF 全文核对，落定术语、参数、疗程、禁忌、标准号 |
| 2 设计 | 固定章节：封面、编制说明、1 范围、2 引用文件、3 术语、4 术前准备、5 操作步骤、6 术后处理、7 注意事项、8 禁忌/不良反应、参考文献、附录A 流程 |
| 3 构建 | 新建临时脚本 `gen_<拼音名>.py`，import 技能生成器，只填 META 与 BLOCKS；排版函数禁改 |
| 4 验证 | 跑 verify_layout.py 门禁（exit=0）；python-docx 复读首尾与关键参数命中抽查；安全自查 |
| 5 交付 | 删除全部临时脚本与下载文件；中文汇报文档链接、权威来源、结构、关键参数与安全红线 |

### 一个俗称对应两项标准时（合编规则）

以《中医穴位包埋操作技术规范》为例："穴位包埋"非国标术语，实际包含两项国标技术——

- GB/T 21709.10—2008 穴位埋线
- GB/T 21709.8—2008 皮内针（埋针）

合编要求：编制说明如实声明为统称并并列两项标准号；术语章为统称单列一条；操作、注意事项、禁忌各章**按技术分节、参数分别照各自国标，禁止混用**；公示稿/征求意见稿不得写入规范性引用文件。

## 四、快速命令（Windows PowerShell，用 `;` 不用 `&&`）

生成文档：

```powershell
cd "c:\Users\Administrator\Desktop\新建文件夹"; python gen_xxx.py
```

排版门禁：

```powershell
cd "c:\Users\Administrator\Desktop\新建文件夹"; python ".trae\skills\tcm-operation-spec-docx\scripts\verify_layout.py" "中医中药涂擦治疗操作技术规范.docx" "新文档.docx"
```

生成器自检：

```powershell
python ".trae\skills\tcm-operation-spec-docx\scripts\build_spec_docx.py" --selftest
```

环境：Python 3.12，依赖 python-docx 0.8.11、pymupdf（均已安装）。

## 五、排版基准（锁定，禁止擅改）

- A4 页面（7772400×10058400 EMU），上下边距 1 英寸、左右约 3.18 cm；Normal 宋体小四（12pt）
- 封面独立成页：黑体22pt主标题 → 楷体14pt英文副标题（**段内分两行**）→ 楷体13pt（操作技术规范）→ 空行×2 → 宋体12pt"适用于"行 → 分页符
- H1 黑体15pt、H2 黑体13pt、H3 黑体12pt
- 正文宋体12pt、1.5 倍行距、首行缩进 482 twips（**非悬挂缩进**）；"——"引用条目与"[n]"文献条目同正文
- "注："注释为楷体10.5pt、灰色 595959
- 基准文档：`中医中药涂擦治疗操作技术规范.docx`

门禁自动检查：页面尺寸与四向页边距、Normal 样式、封面 7 段、H1/H2/H3 字体字号与段间距、全部正文（含短条目）、注释格式。

## 七、维护方法

每新增/修订一份文档后：

1. 更新 SKILL.md 顶部"已用于生成 N 份"计数与名称；
2. 若属新类型（新风险等级、合编、新器材），在 `evals/tcm-spec.eval.md` 追加金标准样例；
3. 新验证过的来源、下载镜像、反爬备选补入 `references/authoritative-sources.md`；
4. 涉及门禁脚本调整时，必须对目录全部 docx 批量回归（历史上薰洗、刮痧各有 1 条"注："误排为正文，已于 2026-09-11 修复并全部 PASS）；
5. 临时脚本、下载的 PDF/txt、`__pycache__` 不保留在技能目录与工作目录。

## 八、常见坑（已固化为自动检查或规则）

- 封面漏两个空行 / 漏分页符 / 英文副标题未分两行
- H3 误用宋体；正文误用悬挂缩进；"注："未用楷体灰字
- 中文正文混入 ASCII 撇号导致 Python SyntaxError
- 把甲技术参数套给乙技术（近名技术未辨析）
- 引用公示稿/征求意见稿或杜撰标准号
- PowerShell 旧版用 `&&` 报错（一律用 `;`）

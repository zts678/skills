# 中医操作技术规范 docx 生成技能

把"检索权威标准原文 → 按固定体例撰写 → 按统一排版生成 docx → 校验 → 清理"这一流程固化为可重复执行的技能。已用于生成 12 份规范（涂擦、热奄包、薰洗、贴敷、耳穴压豆、拔罐、刮痧、推拿、关节松动训练、关节松解术、穴位注射、穴位包埋〔埋线+埋针〕）。

**最高约束：一切技术内容必须来自权威资料原文，禁止凭印象编造参数、分级、剂量、禁忌。查不到权威依据的内容宁可不写。**

## 触发场景

用户在本工作区提出以下任一请求时使用：

- "再创建一份 docx：中医XX操作技术规范.docx"
- "生成/做一份 中医XX治疗操作技术规范"
- 对已生成规范的排版修复（如"封面不一致"）

## 输出位置与命名

- 目录：`c:\Users\Administrator\Desktop\新建文件夹`
- 文件名：`中医<技术名>操作技术规范.docx`（与目录中既有规范同构）；一个俗称对应两项标准的合编文档，用统称命名（如《中医穴位包埋操作技术规范》）
- 生成脚本与下载的资料一律为**临时文件**，用完删除，目录中只保留 docx（历史遗留的 .md 对话记录勿动）
- 本技能的排版基准、脚本与来源库均针对本工作区维护，不跨目录使用

## 工作流程（五阶段）

### 阶段 1 调研——先搞清"是什么技术"，再找标准

1. **辨析同名/近名技术**。中医康复骨伤领域术语易混，例如"关节松动术（mobilization，清醒、无创、关节活动范围内被动手法）"≠"关节松解术（release/arthrolysis/MUA，麻醉下撕开冻结粘连，属有麻醉风险操作）"。拿不准时先检索定义再动笔。
2. 按以下优先级检索权威依据（详细检索式与下载方法见 [references/authoritative-sources.md](references/authoritative-sources.md)）：
   - 团体标准：T/CACM（中华中医药学会）、T/SATCM（地方中医药学会）、T/CRACM、世界中联 SCM、ZYYXH
   - 行业/国家标准：ZY/T、GB、WS/T
   - 全国高等医药院校规划教材（人卫版、中医药版）相应章节
   - 学会专家共识、国家中医重点专科协作组诊疗方案
   - 核心期刊临床研究文献（仅用于补充参数，须标注）
3. **下载原文核对**：优先下载 PDF 用 pymupdf(`fitz`) 提取全文阅读，WebFetch 内容会被截断且不可作为唯一依据。CACM 官网 PDF 若 404，可试镜像站。antpedia 直链对 urllib 返回 403 时，国标全文可从 guifanku.com 标准页 WebFetch、renrendoc 预览页（附录常完整）补齐，必要时多源交叉核对。
4. 提取时必须落定：术语定义、适应证/禁忌证、操作步骤与关键参数（时间、频次、角度、剂量、浓度）、疗程、不良反应、出处标准号。
5. **一个俗称对应两个国标时合编**：如"穴位包埋"=穴位埋线（GB/T 21709.10—2008）+皮内针埋针（GB/T 21709.8—2008）。合编时编制说明必须如实声明该名为统称、并列两项标准号与状态；术语章为统称单列一条并注明本规范用法；操作、注意事项、禁忌各章按技术分节，参数分别照各自国标原文，不得混用；公示稿/未正式发布标准（如 T/CACM 公示稿）不得写入规范性引用文件。

### 阶段 2 设计——固定章节体例

除非权威原文结构另有要求，文档章节固定为：

```
封面（独立一页）
编制说明（技术源流、本文件依据的标准/教材全称及标准号、资质边界注释）
1 范围
2 规范性引用文件（"——"引导的条目列表）
3 术语和定义
4 施术前准备（施术者/环境物品/术前评估/适应证/禁忌证/知情同意）
5 操作步骤与要求（分节到具体手法，参数严格照原文）
6 施术后处理
7 注意事项（编号条目，通常 8～12 条）
8 禁忌 或 不良反应及处理（按技术风险特点择设，高风险技术两者都要）
9 参考文献（[n] 编号，标准写[S]、教材专著[M]、期刊[J]，著录全）
附录A 操作流程概要（资料性附录，一句话箭头流程）
```

封面"适用于"行按技术写适用机构/科室/人员；属有创/麻醉高风险技术时，编制说明下必须加资质边界"注："（医疗机构、执业医师、麻醉/抢救条件、非医疗保健机构禁入等）。

### 阶段 3 构建——脚本生成

1. **首选 import 模式**（脚本短、不可能误改排版函数）：在工作目录新建临时脚本 `gen_<拼音名>.py`，只写 META、BLOCKS，调用技能内生成器：

   ```python
   # -*- coding: utf-8 -*-
   import sys
   sys.path.insert(0, r'c:\Users\Administrator\Desktop\新建文件夹\.trae\skills\tcm-operation-spec-docx\scripts')
   from build_spec_docx import generate
   META = {'title': '中医XX操作技术规范', 'en1': 'Technical specifications of ...',
           'en2': '...', 'apply': '适用于……'}
   BLOCKS = [('h1', '编制说明'), ('body', '……'), ('note', '注：……')]
   if __name__ == '__main__':
       n = generate(META, BLOCKS, r'c:\Users\Administrator\Desktop\新建文件夹\中医XX操作技术规范.docx')
       print('paragraphs:', n)
   ```

   备选：复制 [scripts/build_spec_docx.py](scripts/build_spec_docx.py) 为临时脚本，只替换"内容填写区"。两种方式都**不得改动排版函数**。
2. 内容块类型：`h1/h2/h3`（黑体标题）、`body`（正文，自动含 1.5 倍行距和首行缩进，"——"引用条目与"[n]"文献条目同样用 body）、`note`（"注："楷体灰字）。
3. 排版参数（字号/字体/间距/缩进/封面结构/页面尺寸）见 [references/format-spec.md](references/format-spec.md)，与既有文档逐 twip 对齐。
4. 运行环境：Windows PowerShell，命令间用 `;` 分隔（旧版不支持 `&&`）；Python 3.12 + python-docx 0.8.11、pymupdf 均已装。
5. 中文正文内严禁出现 ASCII 撇号 `'`（会与 Python 单引号字符串冲突报 SyntaxError），英文所有格改写（如 Maitland concept）；生成前自检 `any(chr(39) in t for ...)`。

### 阶段 4 验证——强制门禁

生成后必须运行技能内门禁 [scripts/verify_layout.py](scripts/verify_layout.py)（直接用绝对路径调用，无需复制），以任意一份既有文档为基准对比：

```powershell
cd "c:\Users\Administrator\Desktop\新建文件夹"; python ".trae\skills\tcm-operation-spec-docx\scripts\verify_layout.py" "中医中药涂擦治疗操作技术规范.docx" "新文档.docx"
```

- 页面尺寸与四向页边距、Normal 样式（宋体 sz24）；
- 封面 7 段结构（主标题/英文两行副标题/（操作技术规范）/空行×2/适用于行/分页符段）逐项一致；
- H1（含段前240/段后120）/H2/H3、正文（含"——""[n]"等短条目）、注释的字体字号、行距 360、首行缩进 482 twips 一致；
- 用 python-docx 复读段落总数与首尾内容，并对原文提取的关键参数做命中抽查（如角度、剂量、时间），确认正文无损、参数无漏写；
- 任一项不符 → 修脚本重新生成，不得跳过；退出码非 0 即 FAIL。
- 安全自查：文档与脚本中不得出现任何凭据、个人隐私信息；引用内容不得杜撰标准号。
- 修复存量文档后，应一次性对目录全部 docx 跑回归（门禁为纯签名检查，可批量执行），确保整体一致。

### 阶段 5 交付与清理

1. 删除临时生成脚本、校验脚本副本、下载的 PDF/txt 等全部中间文件（用 DeleteFile，勿留目录）。
2. 向用户中文汇报：文档链接、权威来源（全称+标准号）、文档结构、关键参数与安全红线。
3. 用户指出排版问题时，先用 XML 级检查（python-docx 遍历段落 pPr/rPr）定位差异，再只修差异点；历史上修过的坑：封面缺两个空行/分页符、英文副标题未分两行、H3 误用宋体、条目误用悬挂缩进、注释未用楷体灰色。

## 内容真实性规则

- 每个关键参数都应能在参考文献中找到出处；标准与教材冲突时以标准为准并在编制说明注明。
- 教材没有覆盖的关节/病种，写"参照本规范基本原则，按相应专科诊疗指南实施"，不得替读者发明手法参数。
- 禁忌证要分绝对/相对；高风险操作（麻醉、针刀、出血、骨折风险）的红线必须显式写出。

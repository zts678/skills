# 权威资料检索策略

## 一、资料优先级（从高到低）

1. **团体标准 / 行业标准 / 国家标准原文**
   - T/CACM 中华中医药学会团体标准（如 T/CACM 1179—2019 肩关节周围炎、T/CACM 1063~1064—2018 针刀医学）
   - T/SATCM 上海市中医药学会（如 T/SATCM 0008—2025 麻醉下冻结肩松解手法专家共识）
   - T/CRACM 中国中医药研究促进会、SCM 世界中医药学会联合会
   - ZY/T 中医药行业标准（如 ZY/T 001.1—94 中医病证诊断疗效标准）
   - GB（如 GB 15982—2012 医院消毒卫生标准）、WS/T（如 WS/T 313 手卫生）
   - 医用器材行标/国际标准：YY/T 0105—2020《皮内针》、YY 1116《可吸收性外科缝线》、YY 0043《医用缝合针》、ISO 18746:2016《一次性使用无菌皮内针》
2. **国家中医药管理局发布**：中医医疗技术操作规范、重点专科协作组诊疗方案（如《膝关节僵硬中医诊疗方案》）
3. **规划教材**：人卫版/中医药版全国高等学校教材，如《运动疗法技术学》（纪树荣）、《物理治疗学》（燕铁斌）、《推拿学》《针灸学》《中医骨伤科学》
4. **学会专家共识**（多学科、近年版本）
5. **核心期刊文献**：仅用于补充具体治疗参数，参考文献中按 [J] 著录，不得作为术语/禁忌的唯一来源

## 二、检索式模板

- `"<技术名>" 操作技术规范 团体标准 T/CACM`
- `"<技术名>" 专家共识`
- `"<病名>" 中医 临床诊疗指南 中华中医药学会`
- `"<技术名>" 操作规范 适应证 禁忌`
- 英文技术名加英文检索：`manipulation under anesthesia frozen shoulder guideline`

## 三、PDF 获取与全文提取（已验证可行）

1. WebSearch 找到发布机构页面/PDF 直链；antpedia、学会官网、机构官网常可直接下载。
2. CACM 官网 PDF 可能 404；镜像对象存储（如 `shangia.oss-cn-beijing.aliyuncs.com/p/cacm/uploads/...`）或文件站 `shzyyzz.shzyyzz.com/.../lowqualitypdf/...` 可下。
3. 域名拼写注意核对（如 shszyyxh.org 与 shszyyxx.org 是两个域名，DNS 失败时换变体重试）。
4. 下载与提取代码（urllib + pymupdf，本机已装）：

```python
import urllib.request, ssl, fitz
ctx = ssl.create_default_context(); ctx.check_hostname=False; ctx.verify_mode=ssl.CERT_NONE
req = urllib.request.Request(url, headers={'User-Agent':'Mozilla/5.0'})
open('x.pdf','wb').write(urllib.request.urlopen(req, timeout=60, context=ctx).read())
doc = fitz.open('x.pdf')
open('x.txt','w',encoding='utf-8').write('\n'.join(p.get_text() for p in doc))
```

5. WebFetch 只能做初筛（内容常被截断到 1 万余字），**关键参数以下载的 PDF 全文为准**。
6. 提取后用 Grep 在 txt 中定位"麻醉|松解|手法|剂量|疗程|禁忌"等段落，再 Read 上下文。
7. **下载被拒时的备选链**（已验证）：antpedia 的 img 直链即使加 Referer 也可能 403；此时改用 WebFetch 抓取规范库网页版全文——`guifanku.com/<id>.html` 标准页正文完整（适合 GB/T 21709 系列），`renrendoc.com/paper/<id>.html` 预览常包含资料性附录（如埋线国标附录A～D）；长附录跨页截断时，用带附录条目号的检索式（如 `"埋线" 附录D D3 高热不退`）补齐并多源比对。
8. **公示稿规则**：标题含"公示稿/征求意见稿"或标准号为 `T/CACM ****-202*` 占位形式的文件，属未正式发布版本，只能作为背景参考，**不得写入规范性引用文件，不得引用其中数值参数**（如 2025 年《中医皮内针技术临床应用操作规范》公示稿）。

## 四、必须从原文落定的要素清单

- 术语的中英文及定义出处（如术语来自某标准，注"[来源：……]"）
- 诊断/分期标准（如冻结肩急性期 10～36 周、僵硬期 4～12 个月）
- 适应证、禁忌证（绝对/相对分开，原文列举的病种不得删减也不得添加）
- 操作步骤顺序、体位、助手配合、角度/力度/时间/频次
- 药物：通用名、浓度、剂量（如 0.1% 罗哌卡因、丙泊酚 2～2.5 mg/kg）
- 疗程（如每次 15～20 分钟；每日或隔日 1 次，5～10 次一疗程）
- 术后处理、康复方案、不良反应及处理、出室/离院标准
- 参考文献完整著录（标准[S]含标准号与发布年；专著[M]含出版社；期刊[J]含年卷期页）
